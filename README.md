Intros that turn any static site into a presentation.

![Cursor agents scan a page, then build it element by element](./assets/demo.gif)

```
/plugin marketplace add MD412/macrograce-intros
/plugin install intros-root@macrograce-intros
/plugin install build-intro-agentic@macrograce-intros
```

Other agents: `npx skills add MD412/macrograce-intros`

Then ask your agent to add an intro to the site.
